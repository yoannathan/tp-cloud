# Dossier de préparation TP2

Fichiers fournis : la page `travail/index.html` (version 2), `incident/index.html` (mauvaise page simulée), le modèle `fiche-tp2.txt` et le guide `GUIDE-TP2.md`.

À compléter localement avec les fichiers réels du TP1 : copiez `index.html`, `style.css` et `images/` dans `reference/`, dupliquez-les sous `travail/`, puis constituez `recuperation/` et `sauvegarde-v2/` conformément au guide. La référence doit rester inchangée. L’archive `pharmacie-v2.zip` doit être générée à partir du site restauré/testé puis téléversée **uniquement** dans un nouveau bucket privé.

Consultez [le guide complet](GUIDE-TP2.md) avant les manipulations AWS. Les étapes dangereuses ou modifiant la disponibilité (téléversements sur le bucket public et suppression du marqueur) sont à effectuer avec la vérification de l’enseignant. Aucun bucket, version, marqueur ni capture n’est créé par ce dépôt.
